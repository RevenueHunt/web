# RevenueHunt translation brief (working file — not shipped)

You are translating RevenueHunt marketing copy from English. RevenueHunt makes
**Product Recommendation Quiz** software for ecommerce stores (Shopify, WooCommerce,
BigCommerce, etc.). Audience: ecommerce merchants, marketers, agencies.

## Voice & tone
- Confident, clear, benefit-led, lightly conversational. Not corporate, not hypey.
- Use the **informal register**: ES "tú", FR "tu/vous → use «vous» for FR (standard for
  French B2B SaaS marketing)", DE "du", PT "tu", IT "tu". (For ES/PT/IT/DE: informal. FR: «vous».)
- Sentence case for headings/buttons (only capitalize first word + proper nouns), matching the
  site convention. Do NOT Title-Case.
- Keep sentences tight. Match the source length where possible (UI space matters).

## Always keep in English (do NOT translate)
- Brand & product names: **RevenueHunt**, **Product Recommendation Quiz** (the product name),
  **Shop Quiz**.
- Platform/brand names: Shopify, Shopify Plus, WooCommerce, BigCommerce, Wix, Squarespace,
  Magento, WordPress, Google, Klaviyo, Mailchimp, HubSpot, etc.
- Technical acronyms used as-is: SEO, ROI, CRM, API, PDF, URL, AI, B2B, POS, SKU, UTM.
- "zero-party data" — keep the English term (it has no good localized equivalent); you may gloss
  it on first use if the source does.
- Code, HTML tags/attributes, image paths (`/img/...`), URLs, and internal links — leave EXACTLY
  as-is. Do not translate or re-slug links.

## Formatting rules (markdown pages)
- Preserve the frontmatter keys `legacySlug`, `legacyId`, `legacyUrl`, `featuredImage`, `pubDate`,
  `updatedDate`, `draft` UNCHANGED. Translate only `title` and `description`. Add `lang: "<code>"`.
- Preserve all markdown structure: headings levels, lists, tables, blockquotes, HTML blocks,
  `<YouTube…>`-style embeds, image markup, link targets.
- Translate visible prose, headings, alt text, button/label text. Keep link `href`s unchanged.
- Numbers, prices ($39/mo.), and stats stay as-is (keep "$", keep "/mo." but you may localize the
  "/mo." abbreviation, e.g. ES "/mes", FR "/mois").
