### Transforma clientes casuais em compradores confiantes com um quiz de recomendação de produtos criado para Squarespace Commerce.

A RevenueHunt é um quiz de recomendação de produtos sem código que funciona com qualquer site Squarespace Commerce. Orienta cada cliente até ao produto certo, recolhe zero-party data que a tua equipa de marketing pode realmente usar e liga os resultados às tuas páginas de produto Squarespace, para que o carrinho e o checkout permaneçam nativos no Squarespace.

A maioria dos comerciantes Squarespace lança o seu primeiro quiz em menos de 30 minutos. O quiz vive numa página alojada pelo criador de quizzes ou é incorporado diretamente no teu site Squarespace como um bloco de código - a escolha é tua.

-   **Aumenta as vendas** – Orienta os clientes até a um resultado curado de 2 a 5 produtos, em vez de uma página "ver tudo" avassaladora.
-   **Recolhe dados acionáveis** – Etiqueta cada participante do quiz para campanhas de email e anúncios segmentadas depois.
-   **Sincroniza o teu catálogo Squarespace** – Liga através da exportação CSV de produtos para que o quiz recomende sempre artigos em stock ao preço certo.
-   **Combina com a tua marca** – Personaliza tipos de letra, cores, espaçamento e CSS para que o quiz pareça parte do teu template Squarespace, e não um widget de terceiros.
-   **Suporte premium** – Trabalha com um dos nossos gestores de conta para planear e lançar o teu primeiro quiz.

### Como funcionam os quizzes de recomendação de produtos no Squarespace

Um cliente abre o quiz (incorporação inline, popup ou página de destino dedicada alojada numa página Squarespace) e responde a 4 a 8 perguntas curtas sobre aquilo de que precisa. A lógica condicional ignora automaticamente as perguntas irrelevantes.

Quando o quiz termina, a RevenueHunt avalia cada resposta em relação ao teu catálogo de produtos Squarespace e devolve as 2 a 5 melhores correspondências com uma explicação personalizada por produto. Os clientes clicam para as tuas páginas de detalhe de produto Squarespace, onde adicionam ao carrinho de forma nativa. Cada evento (quiz iniciado, pergunta respondida, resultado visualizado, clique) é enviado para o GA4, o Meta Pixel e a tua plataforma de email.

A incorporação do quiz é leve - normalmente menos de 50KB de JavaScript - pelo que não afeta as pontuações de Core Web Vitals do Squarespace nem o orçamento de desempenho móvel do site.

### O que é diferente nos quizzes no Squarespace

A força do Squarespace são os sites orientados ao design para lojas Commerce de portefólio, com muito conteúdo e de catálogo pequeno. A integração do quiz tira partido dessa força: o quiz incorporado herda por predefinição os tipos de letra e a paleta de cores do teu Squarespace, pelo que parece uma secção nativa em vez de uma ferramenta acoplada.

O ecossistema de apps/extensões do Squarespace é mais pequeno do que o do Shopify, mas o primitivo Code Block (e a Custom Code Injection nos planos Business e superiores) dá-te superfície suficiente para incorporar o quiz de forma limpa. O compromisso: vais precisar de um plano Squarespace Business ou superior para usar a injeção de Code Block. As lojas com plano Personal podem na mesma criar um link para uma página alojada pelo criador de quizzes (o que funciona bem - muitos comerciantes preferem de qualquer forma a página de destino dedicada, já que converte melhor do que uma incorporação para tráfego pago).

### Quando é útil um quiz de recomendação de produtos no Squarespace?

As lojas Squarespace Commerce tendem a ser orientadas ao design, com catálogos curados de 20 a 200 SKUs. O quiz justifica-se quando:

-   O teu catálogo tem variantes (tamanho, aroma, estilo) que precisam de correspondência personalizada
-   Os teus clientes valorizam uma experiência de compra editorial, ao estilo de revista - o quiz encaixa nessa estética
-   Estás a levar tráfego pago para uma página de categoria e as taxas de rejeição são altas
-   Queres recolher endereços de email sem um popup de newsletter genérico
-   Vendes para vários casos de uso (por exemplo, "para mim" vs. "como presente") e queres encaminhar cada cliente para os produtos certos

Principais setores que obtêm os melhores resultados no Squarespace:

-   Beleza, cuidados de pele e cosmética clean
-   Joalharia e acessórios
-   Alimentos e bebidas especiais (vinho, chá, café, azeite)
-   Artigos para casa e decoração
-   Marcas DTC de moda e lifestyle

### Perguntas frequentes

<details>
<summary><strong>Como adiciono um quiz de recomendação de produtos ao meu site Squarespace?</strong></summary>

Regista-te para uma conta RevenueHunt, carrega ou alimenta o teu catálogo de produtos Squarespace, cria o teu quiz e incorpora-o através de um Code Block (plano Business e superiores) ou cria um link para a página de quiz alojada. Não é necessária experiência com código.
</details>

<details>
<summary><strong>Funciona no plano Personal do Squarespace?</strong></summary>

Podes usar a página de quiz alojada (link a partir do teu site Squarespace) em qualquer plano. A incorporação inline completa requer um plano Squarespace Business ou superior, porque é aí que a injeção de Code Block fica disponível.
</details>

<details>
<summary><strong>Existe um quiz de recomendação de produtos gratuito para Squarespace?</strong></summary>

Sim – começa no nosso plano gratuito com 100 respostas de quiz por mês e o criador totalmente desbloqueado. Faz upgrade à medida que escalas; a estrutura do quiz e os dados dos clientes persistem entre os vários níveis.
</details>

<details>
<summary><strong>Como é que o quiz lida com as variantes de produto do Squarespace?</strong></summary>

Se a exportação do teu catálogo incluir variantes, o quiz pode recomendar variantes específicas com base nas respostas dos clientes. Caso contrário, apresenta o produto principal e os clientes escolhem as variantes de forma nativa na página de detalhe de produto Squarespace.
</details>

<details>
<summary><strong>O quiz vai tornar o meu site Squarespace mais lento?</strong></summary>

Não. A incorporação tem menos de 50KB de JavaScript e é carregada com lazy loading por predefinição, pelo que não prejudica os Core Web Vitals. Se tiveres pouco orçamento de desempenho, cria um link para a página de quiz alojada a partir de um botão em vez de incorporar.
</details>

<details>
<summary><strong>Integra-se com o Klaviyo, o GA4 e o Meta Pixel?</strong></summary>

Sim – as respostas do quiz e os produtos recomendados são enviados para perfis ou listas do Klaviyo para fluxos segmentados. O GA4 e o Meta Pixel recebem ambos eventos nomeados (quiz_started, question_viewed, result_viewed, outbound_to_product), para que possas atribuir receita e construir audiências de remarketing.
</details>
